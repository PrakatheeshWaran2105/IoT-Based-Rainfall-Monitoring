# IoT-Based Rainfall Monitoring Using ESP32 and KiwisIoT

## About the Project

The **IoT-Based Rainfall Monitoring System** is an IoT project designed to detect and monitor rainfall conditions in real time.

Using an ESP32 microcontroller and a rain sensor, the system detects rainfall and sends sensor readings to the KiwisIoT platform through Wi-Fi. Users can remotely monitor rainfall activity and view the collected data through the KiwisIoT dashboard.

This project demonstrates how IoT technology can be used for weather monitoring and rainfall observation, providing an easy way to access environmental data from anywhere.
